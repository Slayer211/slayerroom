# RoomLedger — Room Expense Manager

A mobile-friendly room expense tracker. Open `index.html` in a modern browser.

## Included
- Dashboard with totals, category breakdown, recent expenses and roommate balances
- Categories: Lunch, Tiffin, Dinner, Groceries, Water, Current, WiFi, Other
- Add, edit, delete and search expenses
- Choose who paid and who shares each expense; splits equally among selected people
- Roommate balance and suggested settlement calculations
- CSV export and JSON backup/restore
- Local browser storage (no server/account required)

## Use on a phone
For reliable access from multiple devices, publish the folder using a static web host such as GitHub Pages, Netlify or Cloudflare Pages. Upload `index.html` (or the whole folder). Open the published URL on your phone and use the browser's **Add to Home Screen** option.

## Important data note
This starter version saves data only in the browser/device where it is used. It does not sync between devices or users. Use **Room settings → Download backup** regularly. For shared live access across phones, a hosted database and login system would be the next upgrade.
